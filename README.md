# 낙서냥 공부친구 v0.1

갤럭시 탭에서 다른 앱 위에 떠 있는 손낙서 고양이 + 공부 타이머 MVP이다.

## 들어간 기능
- 다른 앱 위에 표시되는 작은 고양이 오버레이
- 고양이 드래그 이동
- 고양이 탭 메뉴: 밥 / 털실공 / 25분 공부
- 자동 배회, 잠자기, 랜덤 응원, 휴식 모션
- 25분 / 50분 공부, 10분 휴식 타이머
- 공부 중 책상에서 같이 공부하는 모션
- 완료한 공부 시간을 날짜별로 저장
- 수능 D-Day 표시 및 날짜 변경
- 기본 시험일: 2026-11-19

## 빌드
Android Studio에서 이 폴더를 열고 Gradle Sync 후 `app`을 실행한다.
권장 JDK는 17이다. Galaxy Tab에서 처음 실행하면 알림 권한과 `다른 앱 위에 표시` 권한을 허용한다.

## 구조
- `MainActivity.kt`: D-Day, 기록, 타이머 컨트롤
- `CatOverlayService.kt`: 오버레이/타이머/랜덤 행동
- `CatOverlayView.kt`: Canvas 기반 손낙서 고양이와 모션
